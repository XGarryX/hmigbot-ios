# 双端场景到态

输入稳定 page/feature/AC ID、应用版本、设备和目标状态。先读页面导航事实与
授权的操作范围；付款、发送或删除等动作遵守该任务授权，不自动补造授权。

1. 每端分别确认实际可调用的设备工具与应用安装状态。
2. iOS 可用 Xcode/设备驱动或用户采集证据；Windows 有 iPhone 不代表存在自动控制 API。
   目标端使用已配置 hdc/测试工具。工具缺失时记录端侧 unavailable。
3. 场景写入口、前置数据/权限/账号状态、动作、期望状态与可观察断言。
   元素优先用稳定标识和无障碍名称；坐标仅在已知设备尺寸/当前截图下使用。
4. 逐步执行并观察回执/新状态，不能用等待时长、点击函数无异常替代状态确认。
5. 源与目标保持等价前置条件；无法达到的状态列原因和最后成功步骤。
6. 保存设备/系统/应用版本、场景、步骤结果、真实截图/录像引用与失败日志。

登录凭据不进 repo 和报告；需要验证码/用户交互时保持该场景 pending，继续独立场景。
返回 observed/pass/fail/not_run，不用空截图或构造 JSON 伪装设备操作。
